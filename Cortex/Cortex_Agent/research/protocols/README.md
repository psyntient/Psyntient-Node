# Research Protocols

One file per named experimental methodology the user has defined, e.g.
`eeg-preprocessing.md`, `qualitative-coding-pass.md`.

Populated by the `research-agent` skill (see
`Cortex_Agent/skills/research-agent/SKILL.md`) — when a project needs a
methodology that isn't here yet, the skill asks the user to describe it, then
saves it here for reuse. Don't invent a protocol on the user's behalf.

Empty until the user defines their first one.
